# 反汇编视图跳转箭头绘制原理

> 对应代码：`ui/memory_window.cpp`
> 核心函数：`memory_window::draw_jump_arrows()`（约 799 行起）
> 效果：x64dbg 风格的跳转箭头 gutter——条件跳转虚线、无条件跳转/调用实线，
> 短箭头贴近代码列、长箭头向外排开，支持悬停高亮与点击跳转。

---

## 0. 总体思路

反汇编表格本身是一个 ImGui Table（第 0 列是留白的 gutter 列）。箭头**不是控件**，
而是表格所有行布局完成后，用 `ImDrawList` 直接"画"在 gutter 列上的一层矢量图形。
整个流程分四个阶段：

```
收集箭头 → 层级分配（重叠避让）→ 几何绘制 → 交互（悬停/点击）
```

关键约束：ImGui 表格的行高、列位置只有真正提交行之后才知道，所以箭头
**必须延迟到行循环结束后统一绘制**（`render_disassembly_view` 末尾）：

```cpp
// ui/memory_window.cpp:676
for (size_t li = 0; li < disasm_lines_.size(); ++li) {
    ...
    // ---- 第 0 列：箭头 gutter（记录每行屏幕坐标，行循环后统一绘制）----
    ImGui::TableSetColumnIndex(0);
    const ImVec2 gp = ImGui::GetCursorScreenPos();
    gutter_x0 = gp.x;                 // gutter 列左边缘（所有箭头的 x 基准）
    row_tops.push_back(gp.y);         // 每行顶部屏幕 y —— 箭头端点的"行→坐标"映射
    ...
}
// 行布局完成后统一绘制箭头层（覆盖在 gutter 之上）
draw_jump_arrows(gutter_x0, row_tops, text_h);
```

`row_tops` 是整个绘制的几何基石：**把"第 i 行"翻译成"屏幕 y 坐标"**。
后文所有端点计算都是 `row_tops[行号] + 行高一半`（取行中心）。

## 1. 数据来源：指令的控制流信息

箭头不需要额外分析，直接消费 Zydis 反汇编时打好的标记
（见 `ui/zydis_disassembler.cpp` 的控制流分类）：

```cpp
struct disasm_line {
    uint64_t    address = 0;
    std::string text;          // 汇编文本
    uint8_t     length = 0;
    bool     is_branch = false;   // jmp/jcc/call/ret 等控制流指令
    bool     is_cond = false;     // 条件跳转（JCC）
    bool     is_call = false;
    bool     is_ret = false;
    uint64_t branch_target = 0;  // 可解析的绝对目标地址；间接寄存器目标为 0
};
```

也就是说每行自带四个正交属性：**是不是跳转、是不是条件、是不是调用、目标地址**。
`ret` 虽然也是 branch 但没有意义（无目标），绘制阶段直接跳过。

### gutter 布局常量

```cpp
// ui/memory_window.cpp:26
constexpr float k_gutter_w  = 50.f;   // 箭头 gutter 列宽
constexpr float k_lane_w    = 8.f;    // 每层箭头的横向间距
constexpr int   k_max_slots = 4;      // 最多层级数（超出丢弃，防遮挡）
constexpr float k_head_w    = 5.f;    // 箭头三角形宽度
```

## 2. 阶段一：收集箭头

遍历所有可视行，把每条"有意义的跳转"打包成一个 `jarrow`：

```cpp
struct jarrow {
    int      src = -1, dst = -1;   // 源/目标 行号
    int      slot = 0;             // 分配到的层级槽位
    bool     cond = false, call = false;
    bool     forward = true;       // 目标在下方（向下跳）
    bool     stub = false;         // 目标不在视图内 → 只画方向短箭头
    bool     assigned = false;
    bool     skip = false;         // 层级用尽，丢弃
    uint64_t from = 0, to = 0;     // 源/目标 地址
};
```

收集循环：

```cpp
for (int i = 0; i < n; ++i) {
    const disasm_line& ln = disasm_lines_[i];
    if (!ln.is_branch || ln.is_ret || !ln.branch_target ||
        ln.branch_target == ln.address)
        continue;                       // ret / 无目标 / 自跳：跳过

    jarrow a;
    a.src = i;
    a.from = ln.address;
    a.to   = ln.branch_target;
    a.cond = ln.is_cond;
    a.call = ln.is_call;

    // 类型开关过滤（工具栏上的 Jcc/Jmp/Call 三个图例 Checkbox）
    if (a.call)      { if (!disasm_show_call_) continue; }
    else if (a.cond) { if (!disasm_show_jcc_)  continue; }
    else             { if (!disasm_show_jmp_)  continue; }

    a.dst = find_idx(a.to);       // 目标地址 → 目标行号
    a.stub = (a.dst < 0);         // 目标行不在当前可视窗口
    a.forward = a.stub ? (a.to > a.from) : (a.dst > a.src);
    arrows.push_back(a);
}
```

三个要点：

1. **目标行查找用二分**。反汇编行地址严格递增，`find_idx` 是标准二分查找，
   O(log n) 把目标地址映射为行号：

   ```cpp
   auto find_idx = [&](uint64_t addr) -> int {
       int lo = 0, hi = n - 1;
       while (lo <= hi) {
           const int mid = (lo + hi) / 2;
           if (disasm_lines_[mid].address == addr) return mid;
           if (disasm_lines_[mid].address < addr) lo = mid + 1;
           else hi = mid - 1;
       }
       return -1;
   };
   ```

2. **`stub`（残箭头）**：目标跳出了当前反汇编窗口（滑动窗口只有可视行的
   3 倍大），画不出完整箭头，退化为"源行一小段横线 + 一个朝上/朝下的
   短三角"，仅指示方向。
3. **`forward` 判定**：完整箭头用行号比较；stub 没有行号，退化为地址比较。

## 3. 阶段二：层级分配——区间图贪心着色

**问题**：两条箭头在行区间上重叠时（比如一个跨 20 行的 `jmp` 和一个跨 5 行的
`jcc`），如果画在同一条竖线上会互相压线。x64dbg 的做法是让它们占不同的
"层"（lane）：短箭头贴近代码列，长箭头依次向外排。

**数学本质**：把每条箭头 `[min(src,dst), max(src,dst)]` 看成一个区间，
重叠的箭头不能同槽 —— 这就是经典的**区间图着色问题**（interval graph
coloring），"最少槽数 = 最大重叠数"。本实现用**贪心着色**近似求解：

### 3.1 排序策略：短箭头优先

```cpp
std::sort(order.begin(), order.end(), [&](int x, int y) {
    const int sx = /* |dst - src| */;
    const int sy = /* |dst - src| */;
    return sx != sy ? sx < sy : x < y;
});
```

按跨度**升序**处理：短箭头先抢最内层（slot 0，最贴近代码列），长箭头
自然被挤到外层。这符合视觉直觉——最常看的短跳转离代码最近。
（注意 stub 被排除在排序之外，它们只有一小段，永远画 slot 0 位置附近。）

### 3.2 贪心占槽

```cpp
auto overlaps = [](const jarrow& a, const jarrow& b) {
    const int a1 = ImMin(a.src, a.dst), a2 = ImMax(a.src, a.dst);
    const int b1 = ImMin(b.src, b.dst), b2 = ImMax(b.src, b.dst);
    return a1 <= b2 && b1 <= a2;      // 区间相交（含共享端点）
};

for (int idx : order) {
    bool used[k_max_slots] = {};
    for (const jarrow& o : arrows)
        if (o.assigned && overlaps(arrows[idx], o))
            used[o.slot] = true;      // 已分配且与当前箭头重叠的槽位不可用
    int s = 0;
    while (s < k_max_slots && used[s])
        ++s;
    if (s >= k_max_slots)
        arrows[idx].skip = true;      // 层级用尽，丢弃防遮挡
    else {
        arrows[idx].slot = s;
        arrows[idx].assigned = true;
    }
}
```

对每条箭头，扫描所有**已分配**箭头，把它们占掉的槽位标记为不可用，然后
取最小可用槽位。这是 O(k·n) 的贪心（k = 已分配数）。

两个工程取舍：

- **重叠判定含共享端点**（`a1 <= b2 && b1 <= a2`）：首尾相接的两条跳转
  （例如循环的回边与下一条的前向边）也会分槽，避免三角箭头叠在同一行。
- **k_max_slots = 4 上限**：极少数"箭头扇形交叠"超过 4 层时直接丢弃
  （`skip = true`），保证 gutter 宽度有限时不出血、不遮挡代码列。

> 复杂度：排序 O(n log n) + 贪心 O(n²)（n 是可视跳转数，通常 < 30），
> 每帧执行毫无压力。

## 4. 阶段三：几何绘制

### 4.1 关键 x 坐标

```cpp
const float x_tip  = gutter_x0 + k_gutter_w - 8.f;   // 箭头尖端（贴近地址列）
const float x_base = x_tip + k_head_w;               // 三角底边
...
const float lane_x = x_tip - 4.f - (float)(a.slot + 1) * k_lane_w;
```

- `x_tip`：所有箭头三角形尖端的 x（靠 gutter 右缘，指向地址列方向其实是
  指向"目标行"，三角是横向的）；
- `lane_x`：第 `slot` 层竖线的 x —— 越外层越靠左，每层间隔 `k_lane_w = 8px`。

### 4.2 正交折线 + 三角箭头

完整箭头是标准的三段"日字形"走线（横—竖—横），条件跳转画虚线：

```cpp
const bool dashed = a.cond && !a.call;   // 条件跳转虚线，其余实线

if (!a.stub) {
    const float yd = row_tops[a.dst] + text_h * 0.5f;
    draw_seg(dl, ImVec2(lane_x, ys), ImVec2(x_base, ys), col, th, dashed);  // 源横线
    if (fabsf(yd - ys) > 0.5f)
        draw_seg(dl, ImVec2(lane_x, ys), ImVec2(lane_x, yd), col, th, dashed);  // 竖线
    draw_seg(dl, ImVec2(lane_x, yd), ImVec2(x_base, yd), col, th, dashed);  // 目标横线
    // 目标端箭头（指向代码列）
    dl->AddTriangleFilled(ImVec2(x_base, yd), ImVec2(x_tip, yd - 3.2f),
                          ImVec2(x_tip, yd + 3.2f), col);
}
```

stub（目标不在视图）只画源横线 + 一个 8px 的方向短竖线和小三角：

```cpp
} else {
    const float yend = ys + (a.forward ? 8.f : -8.f);
    draw_seg(dl, ImVec2(lane_x, ys), ImVec2(x_base, ys), col, th, dashed);
    draw_seg(dl, ImVec2(lane_x, ys), ImVec2(lane_x, yend), col, th, dashed);
    const float tip_y = yend + (a.forward ? 3.f : -3.f);
    dl->AddTriangleFilled(ImVec2(lane_x, tip_y),
                          ImVec2(lane_x - 3.f, yend),
                          ImVec2(lane_x + 3.f, yend), col);
}
```

### 4.3 虚线的模拟：手动分段

`ImDrawList` 没有原生虚线，`draw_seg` 用"沿向量按固定步长分段画短实线"
模拟（本质是沿单位向量做参数化采样）：

```cpp
void draw_seg(ImDrawList* dl, const ImVec2& a, const ImVec2& b,
              ImU32 col, float th, bool dashed)
{
    if (!dashed) {
        dl->AddLine(a, b, col, th);
        return;
    }
    const float dx = b.x - a.x, dy = b.y - a.y;
    const float len = sqrtf(dx * dx + dy * dy);
    if (len < 1.f) return;
    const float ux = dx / len, uy = dy / len;      // 单位方向向量
    constexpr float k_dash = 4.f, k_gap = 3.f;
    for (float t = 0.f; t < len; t += k_dash + k_gap) {   // 弧长参数 t
        const float t2 = t + k_dash < len ? t + k_dash : len;
        dl->AddLine(ImVec2(a.x + ux * t, a.y + uy * t),
                    ImVec2(a.x + ux * t2, a.y + uy * t2), col, th);
        if (t2 >= len) break;
    }
}
```

### 4.4 视觉编码：颜色 / 透明度 / 线宽

**颜色按类型区分**，且随主题背景亮度自动切换深浅两套配色：

```cpp
void arrow_palette(ImVec4& jcc, ImVec4& jmp, ImVec4& call)
{
    const ImVec4 bg = ImGui::GetStyleColorVec4(ImGuiCol_WindowBg);
    const bool light = (bg.x * 0.299f + bg.y * 0.587f + bg.z * 0.114f) > 0.5f;
    if (light) {
        jcc  = {0.28f, 0.34f, 0.44f, 0.85f};   // 条件跳转：暗灰蓝（虚线）
        jmp  = {0.80f, 0.42f, 0.02f, 0.90f};   // 无条件跳转：橙（实线）
        call = {0.05f, 0.38f, 0.78f, 0.90f};   // 函数调用：蓝（实线）
    } else { /* 深色主题下一套更亮的 */ }
}
```

（亮度用 **Rec.601 加权** `0.299R + 0.587G + 0.114B` 计算，是人眼感知亮度
的标准近似。）

**透明度按跳转距离衰减**——距离越远越淡，把视觉重点留给局部跳转：

```cpp
float alpha = base->w;
if (!a.stub) {
    const float span = (float)abs(a.dst - a.src);
    alpha *= 1.0f - 0.45f * ImMin(span / (float)n, 1.0f);
    // 跨全屏的箭头最低衰减到原透明度的 55%
}
```

**线宽强调选中行相关箭头**：源行或目标行是当前选中地址时，线宽 1→2：

```cpp
const bool related = (disasm_lines_[a.src].address == disasm_selected_) ||
                     (!a.stub && disasm_lines_[a.dst].address == disasm_selected_);
float th = related ? 2.0f : 1.0f;
```

## 5. 阶段四：交互（命中测试 / 悬停 / 点击跳转）

### 5.1 线段级命中测试

箭头不是 ImGui 控件，无法用 `IsItemHovered`，需要自己拿鼠标坐标对
**每条线段做距离盒测试**（各向外扩 2~3px 的容差，等价于"点到线段的
L∞ 距离"判定）：

```cpp
auto near_h = [&](float x1, float x2, float y) {   // 水平线段
    return mouse.y > y - 3.f && mouse.y < y + 3.f &&
           mouse.x > ImMin(x1, x2) - 2.f && mouse.x < ImMax(x1, x2) + 2.f;
};
auto near_v = [&](float x, float y1, float y2) {   // 垂直线段
    return mouse.x > x - 3.f && mouse.x < x + 3.f &&
           mouse.y > ImMin(y1, y2) - 2.f && mouse.y < ImMax(y1, y2) + 2.f;
};

bool hov = near_h(lane_x, x_base, ys);             // 先测源横线
if (!hov && !a.stub) {
    const float yd = row_tops[a.dst] + text_h * 0.5f;
    hov = near_v(lane_x, ys, yd) || near_h(lane_x, x_base, yd);  // 再测竖线/目标横线
} else if (!hov && a.stub) {
    hov = near_v(lane_x, ys, ys + (a.forward ? 8.f : -8.f));
}
```

逐段测试三段折线，任意一段命中即整条箭头命中；命中后该箭头透明度拉满、
线宽加粗，并记录 `hovered` 索引。

### 5.2 Tooltip 与点击跳转

```cpp
if (hovered >= 0) {
    const jarrow& a = arrows[hovered];
    const char* tname = a.call ? "CALL (函数调用)"
                      : a.cond ? "JCC (条件跳转)"
                               : "JMP (无条件跳转)";
    snprintf(tip, ..., "%s\n%016llX  ->  %016llX\n距离 %lld 字节\n点击箭头跳转到目标", ...);
    ImGui::SetTooltip("%s", tip);
    if (ImGui::IsMouseClicked(ImGuiMouseButton_Left))
        disasm_jump_to(a.to);     // 点击箭头 = Follow，直接重锚反汇编窗口
}
```

`disasm_jump_to` 会重置解码基址、清空前进历史并把滚动归零（见
`memory_window.cpp`），实现"点箭头即跟随跳转"。

## 6. 与 x64dbg 原版的对应关系

| x64dbg 行为 | 本实现 |
|---|---|
| 箭头画在地址左侧 gutter | 第 0 列固定 50px gutter，`ImDrawList` 覆盖绘制 |
| 条件跳转虚线、jmp/call 实线 | `dashed = cond && !call`，手动分段模拟虚线 |
| 短箭头靠内、长箭头靠外 | 区间图贪心着色，跨度升序分配槽位 |
| 目标不可见时画方向残箭头 | `stub` 分支：8px 短竖线 + 三角 |
| 悬停高亮、点击跟随 | 线段级命中测试 + `disasm_jump_to` |

## 7. 小结（算法清单）

| 环节 | 算法 | 复杂度 |
|---|---|---|
| 目标地址 → 行号 | 二分查找 | O(log n) |
| 层级分配 | 区间图贪心着色（跨度升序） | O(n²)，n 为可视跳转数 |
| 虚线 | 向量参数化分段采样 | O(len/7) |
| 悬停检测 | 线段 AABB 容差测试 | O(箭头数 × 3 段) |
